\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}

This Research Internship is part of the early validation work of the HybridNeuroPerception project. The main goal is to build the basic processing workflows for frame-based vision and event-based vision on embedded platforms, and to verify real-time event data transfer between Kria and Jetson. First, a frame-camera object detection system was established on the NVIDIA Jetson Orin. This included real-time object detection with \texttt{jetson-inference}, a C++ Intersection over Union (IoU) tracking prototype, and a basic detection evaluation using the KITTI dataset. After that, the Recurrent Vision Transformers (RVT) model was deployed on the Jetson. The Prophesee GEN1 dataset was used for offline event-based object detection validation and for visualization of predictions and ground-truth annotations. The complete GEN1 validation achieved a mean Average Precision (mAP) of 45.77\%, an AP50 of 71.06\%, and an AP75 of 48.80\%.

For the event-camera part, this work set up a platform with the AMD Kria KV260 Vision AI Starter Kit and the Prophesee IMX636, and completed the acquisition and display of real event streams. The Metavision ROS 2 driver on the Kria packages the raw events into \texttt{EventPacket} messages and sends them to the Jetson through Robot Operating System 2 (ROS 2). On the Jetson, \texttt{event\_camera\_codecs} and \texttt{event\_camera\_renderer} run in Docker to decode and render the events. The results are then displayed with \texttt{rqt\_image\_view} on the Jetson host.

In the final tests, the Jetson could continuously receive the events published by the Kria. During stable operation, the observed \texttt{EventPacket} message rate was about 52--55 Hz. In normal dynamic scenes, the observed event-topic throughput was mainly about 11.6--14.2 MB/s. With the current rate-limiting configuration, the throughput was about 20 MB/s during fast motion and about 1.2--1.9 MB/s after the camera was covered and the scene had little change. The renderer could continuously generate event images, which were also continuously displayed on the host. The results show that the current distributed Kria--Jetson architecture can transfer, decode, render, and visualize real event streams. They also show that the amount of event data changes clearly with scene dynamics. This provides a basis for later real-time event-based object detection and further hardware optimization.

\textit{\textbf{Keywords: }Event camera, Embedded vision, Object detection, RVT, Kria KV260, NVIDIA Jetson, ROS 2}
