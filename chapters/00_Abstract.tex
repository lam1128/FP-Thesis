\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}

This Research Internship validates key components of the HybridNeuroPerception project on embedded platforms. The work establishes frame-based and event-based vision workflows and verifies real-time event data transfer between Kria and Jetson. On the NVIDIA Jetson AGX Orin, a frame-camera baseline was implemented with \texttt{jetson-inference}, a C++ Intersection over Union (IoU) tracker, and a basic KITTI evaluation. The Recurrent Vision Transformers (RVT) model was then deployed for offline GEN1 validation.

For real event data, the Metavision starter kit used in this work consists of a Prophesee IMX636 sensor and an AMD Kria KV260 Vision AI Starter Kit. A ROS 2 driver for the MIPI-CSI-connected IMX636 sensor was developed. On the Jetson, \texttt{event\_camera\_codecs} and \texttt{event\_camera\_renderer} decode and render the events in Docker, while \texttt{rqt\_image\_view} displays the results on the host.

Final tests confirmed continuous event transfer from the Kria to the Jetson. Continuous rendering and display confirmed that the Kria--Jetson pipeline can transfer, decode, render, and visualize real event streams. The results also show that event-data volume changes with scene dynamics and provide a basis for later real-time event-based object detection and hardware optimization.

\textit{\textbf{Keywords: }Event camera, Embedded vision, Object detection, RVT, Kria KV260, NVIDIA Jetson, ROS 2}
