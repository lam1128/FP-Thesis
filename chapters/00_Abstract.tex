\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}

This Research Internship validates key components of the HybridNeuroPerception project on embedded platforms. The work establishes frame-based and event-based vision workflows and verifies real-time event data transfer between Kria and Jetson. On the NVIDIA Jetson Orin, a frame-camera baseline was implemented with \texttt{jetson-inference}, a C++ Intersection over Union (IoU) tracker, and a basic KITTI evaluation. The Recurrent Vision Transformers (RVT) model was then deployed for offline GEN1 validation, achieving 45.77\% mAP, 71.06\% AP50, and 48.80\% AP75.

For real event data, the AMD Kria KV260 Vision AI Starter Kit and Prophesee IMX636 were used. The Kria publishes EVT3 \texttt{EventPacket} messages through ROS 2. On the Jetson, \texttt{event\_camera\_codecs} and \texttt{event\_camera\_renderer} decode and render the events in Docker, while \texttt{rqt\_image\_view} displays the results on the host.

Final tests showed a stable \texttt{EventPacket} message rate of about 52--55 Hz. The observed throughput was mainly 11.6--14.2 MB/s in normal dynamic scenes, about 20 MB/s during fast motion under the current rate-limiting configuration, and 1.2--1.9 MB/s after the camera was covered. Continuous rendering and display confirmed that the Kria--Jetson pipeline can transfer, decode, render, and visualize real event streams. The results also show that event-data volume changes with scene dynamics and provide a basis for later real-time event-based object detection and hardware optimization.

\textit{\textbf{Keywords: }Event camera, Embedded vision, Object detection, RVT, Kria KV260, NVIDIA Jetson, ROS 2}
